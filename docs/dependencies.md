# Dependências do Ecossistema

*   **Core**: React 18, React-DOM.
*   **Bundler**: Vite.
*   **Estilos**: Tailwind CSS, PostCSS, tailwind-merge, clsx.
*   **Ícones**: Lucide React.
*   **Backend**: Express.js, esbuild, dotenv.
*   **Banco de Dados/Infra**: Firebase SDK (Client `firebase`, Server `firebase-admin`).
*   **Inteligência Artificial**: SDK GenAI (`@google/genai`).
*   **Utilitários**: QRCode.
*   **Execução Backend Dev**: TSX.

**Status das Bibliotecas**: Todas cruciais e funcionais, sem excesso aparente (Sem bibliotecas de form ou state management legadas listadas, favorecendo o Context nativo do React).

# Glossário

*   **Tenant / Workspace**: Espaço de dados exclusivo e isolado de um cliente corporativo.
*   **Membership**: Elo de conexão que valida e guarda o cargo (`CompanyRole`) do usuário num Workspace específico.
*   **Entitlement**: Um direito ou permissão cedida pela assinatura contratada (ex: permissão de possuir Filiais ou possuir Módulo IA).
*   **HQ (Headquarters)**: Plataforma Central reservada aos Engenheiros ou Donos da infraestrutura para administração SaaS do software VarejoPro.
*   **POS (Point of Sale)**: Interface focada da frente de caixa para operadores realizarem vendas e recebimentos em tempo real.
*   **Offline-First**: Metodologia onde a UI reage primeiro as memórias locais e deposita comandos de requisições falhas em filas para serem enviadas quando houver banda de internet estável.
*   **Idempotency**: Padrão REST e de arquitetura para impedir processamento redundante quando há múltiplos cliques de submissão ou retentativas automáticas num ambiente instável de conectividade.

# VAREJOPRO HQ — DEVELOPER PLATFORM CONSOLE

O Headquarters (HQ) do VarejoPro NÃO É um painel administrativo destinado a clientes, donos de loja ou gerentes do varejo.

O HQ é a **Estação de Controle Master dos Administradores do SaaS (Engenharia de Plataforma)**. É a central de comando restrita aos criadores e detentores do VarejoPro, permitindo auditar o uso multitenant, corrigir contas, estender Trials de empresas pagantes e manipular os recursos dos clientes sob demanda ou suporte.

*   *Caminho de Acesso Front-End*: `/src/modules/hq/VarejoProHQ.tsx`
*   *Backend Routes*: `/server/routes/hq.routes.ts`
